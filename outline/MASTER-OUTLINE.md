# 《霓虹尘埃》— 完整故事大纲

## 一、基础信息

| 维度 | 设定 |
|------|------|
| **书名** | 《霓虹尘埃》（备选：《义体》《钢铁霓虹》《深渊医生》） |
| **类型** | 科幻·赛博朋克·都市热血 |
| **篇幅** | 长篇，5卷，预计 400-500 章，120 万字+ |
| **文风** | 硬核接地气，霓虹美学+底层烟火气+热血打斗 |
| **核心主题** | 向上爬的每一步，脚下都踩着珍视之人的碎片 |

## 二、世界观：新天城

### 城市结构（垂直分层）

```
🟡 云顶区（0.1%人口）— 三大公司总部，人工阳光，永生者议会
🟠 中枢区（10%人口）— 公司中产，全义体化生活，信用评分体系
🔴 地下区（90%人口）— 霓虹贫民窟，黑市横行，永不见天日
⬛ 废墟层 — 废弃工厂/旧城区，帮会割据，法外之地
```

### 三大公司

| 公司 | 领域 | 核心设定 |
|------|------|---------|
| **泰坦生物** | 基因/器官/生物义体 | 掌控「灵魂协议」——签了就欠一辈子，死后身体归公司 |
| **神经科技** | 脑机接口/记忆/意识 | 「云端永生」项目——上传你的人，留下你的钱 |
| **铁穹军工** | 战斗义体/武器/安保 | 公司武装力量，镇压一切反抗 |

### 核心矛盾

- **「灵魂协议」**：不改造就没工作，改造了死后身体都不属于自己
- **「信用锁」**：义体按月付费，断供就远程锁定——人还活着，四肢动不了
- **「赛博精神病」**：义体改造超过 70%，神经系统开始崩溃

### 地下帮会格局

| 帮会 | 地盘 | 特征 |
|------|------|------|
| **血手帮** | 废墟层东区 | 暴力至上，军火走私 |
| **蛇牙会** | 废墟层西区 | 情报贩子，暗杀 |
| **铁拳兄弟会** | 地下区+废墟层交界 | 底层工人互助起家，重义气，主角后期势力基础 |

## 三、核心人物

### 主角：林深（Lín Shēn）

| 维度 | 设定 |
|------|------|
| **年龄** | 22岁（开篇） |
| **身份** | 地下区黑市义体医生 → 帮会技术顾问 → 「钢铁医生」→ 地下势力首领 |
| **外表** | 清瘦，常年戴口罩，手指修长有老茧（手术练的），左臂全义体化（被迫改造） |
| **性格** | 沉静克制，外冷内热，极度护短，做事有底线但很少说 |
| **核心驱动** | 治好妹妹的病，带她看一次真的太阳 |
| **底线** | 不改造未成年人（来自对妹妹的保护） |
| **最大弱点** | 太重感情——每一次牺牲都不是被逼的，是自己选的 |

### 女主角：苏焰（Sū Yàn）

| 维度 | 设定 |
|------|------|
| **年龄** | 21岁 |
| **第一层身份** | 铁拳兄弟会战斗队长，绰号「红焰」，双手战斗义体，近战无敌 |
| **第二层身份** | 泰坦生物「灰衣特工」，直属公司高层，任务是监控地下势力 |
| **外表** | 红色短发，右脸有一道义体接口的金属纹路，笑起来痞气十足 |
| **性格** | 表面火爆直接，内里极度孤独——两个身份都没有真正属于她的位置 |
| **核心矛盾** | 她来监控主角，却在主角身上第一次感受到「被当成真正的人」 |
| **最终选择** | 背叛泰坦生物，被强制改造为战斗兵器，主角不得不亲手终结她 |

### 妹妹：林小满（Lín Xiǎomǎn）

| 维度 | 设定 |
|------|------|
| **年龄** | 14岁（开篇）→ 18岁（结局） |
| **病症** | 「神经退行性崩溃」——原生神经系统在污染环境中加速衰竭 |
| **唯一解** | 泰坦生物的「神经重塑」手术，费用是天价 |
| **在故事中的角色** | 不是花瓶——她自学编程，中后期成为主角的技术后勤 |
| **与苏焰的关系** | 最初敌视（觉得苏焰会伤害哥哥），后来成为苏焰唯一真正信任的人 |
| **最终命运** | 主角最终凑够了手术费，但苏焰在最后一战牺牲。活下来的妹妹说：「原来外面真的有太阳。」 |

### 核心配角

| 角色 | 身份 | 定位 |
|------|------|------|
| **老狗** | 主角的废品供应商，独臂老人 | 父亲般的角色，第一卷结尾为保护主角而死 |
| **铁牙** | 铁拳兄弟会首领 | 主角的引路人/老大哥，第四卷反目 |
| **乌鸦** | 蛇牙会情报贩子 | 游走灰色地带的信息源，立场暧昧 |
| **白博士** | 神经科技叛逃科学家 | 提供关键技术，亦正亦邪 |
| **赵理事** | 泰坦生物中层，苏焰的直属上司 | 主要反派之一，阴险型 |

## 四、五卷大纲

### 第一卷：「地下医生」— 底层挣扎
**篇幅：** 约 80 章 | **基调：** 灰暗中的微光
**主线：** 林深是地下区最好的黑市义体医生。妹妹病情恶化，必须在三个月内凑齐手术费。帮会送来重伤的苏焰，指定他救。卷入帮会冲突，老狗之死，第一次杀人，签下灵魂协议。

### 第二卷：「钢铁兄弟」— 帮会崛起
**篇幅：** 约 100 章 | **基调：** 热血与阴暗交替
**主线：** 加入铁拳兄弟会，建立义体工坊，三帮大战，破解义体信用锁，苏焰身份暴露。

### 第三卷：「身世之秘」— 血与真相
**篇幅：** 约 100 章 | **基调：** 悬疑与反转
**主线：** 发现父母是泰坦永生项目的科学家，被公司清洗。妹妹的病是基因锁。苏焰彻底叛变。铁牙背叛。

### 第四卷：「钢铁王座」— 深渊夺权
**篇幅：** 约 100 章 | **基调：** 黑暗中的崛起
**主线：** 重建铁骨诊所网络，断供运动，苏焰被远程控制，林深同步痛觉分担伤害。赛博精神病出现。攻入中枢区。

### 第五卷：「霓虹尽头」— 终局与代价
**篇幅：** 约 120 章 | **基调：** 悲壮而温暖
**主线：** 进攻云顶区，对决永生者议会。苏焰被改造为兵器，林深亲手终结。消灭永生者。妹妹重生。林深赛博精神病不可逆。终章——妹妹走出新天城，看到真的太阳。

## 五、三条情感线

| 卷 | 得到 | 失去 |
|-----|------|------|
| 一 | 苏焰、兄弟会 | 老狗（死） |
| 二 | 势力、地位 | 对苏焰的信任（首次动摇） |
| 三 | 身世真相、苏焰的真心 | 铁牙（背叛）、过去的自己 |
| 四 | 地下之王、与苏焰羁绊 | 右手（最后的原装身体） |
| 五 | 胜利、妹妹的新生 | 苏焰（亲手终结）、自己（赛博精神病） |
