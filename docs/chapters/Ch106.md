# 第二卷·第二十六章：「白博士」

## 一

林深在离开白沙中转站后没有直接返回废城。

他走了大约八百米，在中转站北出口外的废弃加油站停下了脚步，蹲在一根倾倒的混凝土电线杆后面，拿出黑星给他的那张旧地图，用手指在纸面上画了一条路线。苏焰站在他身侧，没有催促他，只是背对着他，视线覆盖着他们来路的方向。

地图上用圆珠笔标记了三个点。标注「B-7」的是他们进入的中转站入口。标注「西区」的是「末班车」的位置——已经去过。标注「旧医院」的第三个点，位于白沙中转站东侧大约两公里处，不在地图上标示出的任何主要通道上，是一段需要自行穿越废弃建筑群的路线。

黑星告诉他这个位置的时候没有多说。只告诉了他一句话：「他的数据中心不在中转站里面——他在地下。」

林深把地图折好塞回内袋。在站起来之前，他做了五秒钟的静止——让刚才在「末班车」后厅里接收到的所有信息在大脑里沉降了一次。克莱恩即将死去的事实。铁穹的人已经进入中转站的事实。钱爷在资助泰坦核心实验室搬迁的事实。那段录音的重量还在他夹克内袋里，但他知道它真正的价值不是现在——是在某个他还看不见的未来节点上，这段音频会成为一枚可以被引爆的装置。

但那是以后的事。现在要做的是眼下的事——找到白景行。

「东面。」林深站起来的时候说了一句，没有更多解释。

苏焰没有问目的地。她只是调整了身体朝向，把警戒方向从西北侧切换到了东侧。

他们开始穿越废弃建筑群的路程。这一段路没有苔藓照明——头顶的穹顶结构在这个区域已经完全坍塌，在长达几十米的距离上方是裸露出土壤层的废墟堆，脚下的路面覆盖着从上方掉落的风化混凝土碎块和锈蚀的金属管件。林深的靴底踩到一根断裂的钢筋时，它的两端卡在碎块之间发出了一声金属的脆响——像旧时代的一种信号铃，在空旷的废墟里拖着一条微弱的余音消失在远处。

「这里有人住过。」苏焰说。不是疑问句。

林深也注意到了。废墟两侧的墙壁上有近期被清理过的痕迹——有人把大片倒塌的碎块推到了走廊两侧，在中间清出了一条可以通行的小径。清理的方式不是机械的——没有人用铲车或液压设备来干这种活——是用人力一块一块地搬开的。林深在一个拐角处看到了堆积物边缘的手印——指印大小，成年男性的手掌，泥土嵌在手指的纹路里留下的印记。

「白景行一个人清理的。」林深说，「他在为自己留退路。」

「退路为什么要通到废弃医院？」

「因为没有人会在废弃医院的太平间里翻找东西。」

苏焰沉默了两秒，然后说了一种林深没有预料到的东西——不是分析，是决定：「我进去。你在外面。」

「为什么？」

「因为如果白景行在里面，他能认出你——也能认出你不是来杀他的。但如果你带着我进去，他会以为你带了保镖。你带保镖来见一个在太平间躲了三个月的人——他会认为你想从他身上拿东西走，不是想和他说话。」

林深看着苏焰。这句话说得很平凡，语气平淡得像在说一段交通路线的走法——但林深听出了这句话背后的重量。苏焰在以她的方式理解这场对话的性质，并且在调整自己的角色以适应局势。

「一百米距离。」林深说，「你留在一百米的位置。」

「够了。」

他们没有再多交流。林深将背包从肩上取下来，放在废墟墙角一个相对干燥的位置——不需要带着它进入医院——然后转身沿着那条被清理过的小径继续向前走。

大约三分钟后，废弃医院的轮廓出现在视野中。

林深见过很多废墟，但这座医院给人一种不同的感觉——不是破败，是被遗弃的方式有一种异样的整洁感。建筑的外立面大部分保持完整，玻璃窗约有百分之六十被打破了，但剩下的百分之四十被用一种半透明的旧塑料薄膜从内部封住了。门口的金属框架旋转门被卡在了半开的位置——一扇门板向内侧倾斜着，在风经过时发出一种低沉的、持续不断的呜呜声，像是建筑自己在呼吸。

林深站在门口停了片刻。

夜风穿过那扇倾斜的旋转门的缝隙，带出了一股气味——不是腐臭，是消毒液用完之后残留的气味底子，混合着陈旧的纸张、霉菌和金属。一种医院特有的气味，在被时间稀释之后仍顽固地附着在建筑的每一个角落。

他推开了那扇倾斜的旋转门。

## 二

医院的门厅比外面看起来宽敞。地面铺设的旧瓷砖还大体保持着原位，虽然大部分已经开裂。原本的导诊台只剩下一个空荡荡的木质框架——台面被拆走了，只剩下底部支撑结构和抽屉格子的空壳，像一具被掏空了内脏的动物骨骼骨架。

林深在大厅中停了三秒，确认了一下建筑的内部结构。一楼的布局和大多数旧时代综合医院一致：中央导诊台，左侧是急诊通道，右侧通向门诊区域，后方是一排电梯井和消防楼梯的入口。但电梯井的门全部敞开着——轿厢早已消失，只剩下黑漆漆的竖井和垂挂在井口处断裂的钢丝缆绳。

常规入口全都不能使用。这意味着白景行在他所处的位置留下了通行的路径——而林深需要找到那条路径。

他走向消防楼梯入口。

楼梯间是这座建筑中唯一完全黑暗的区域——没有来自外部的光线，没有苔藓，没有任何光源。林深在入口处停住了，用左手在墙壁上摸索了片刻——找到了一个老旧的、固定在墙体上的扶手杆，表面覆盖着厚厚的灰尘。他把左手按在扶手上，开始向下走。

每一级台阶都承受了他的体重，发出轻微的咯吱声，但在楼梯间的回音效果下，这声音被放大成了清晰的脚步声。林深没有刻意放轻脚步——他不需要让白景行不知道有人来了，他只需要让白景行知道他是一个人来的。

地下二层。

楼梯间的门被一块金属板从内侧封住了。林深在门板表面摸到了焊点——不是从这一侧焊上的，是从门的内侧焊死的。这意味着地下二层被改造成了封闭空间——白景行在把自己关进去。

但白景行总得进出。

林深退后半步，没有尝试撬开门板。他抬头看向楼梯间的天花板——在上方的管道井口，有一个大约六十乘六十厘米的检修口，盖板被人从内侧用铁丝简单固定了，但铁丝已经生锈到一拉就断的程度。

林深踩上楼梯扶手，单手钩住检修口的边缘，用力将生锈的铁丝扯断，然后翻身上了管道井。

管道井的高度不够他站立——他在里面只能弯腰行进，头顶距离管道井的内壁不到十厘米。但他能看到前方大约十米处有光线——不是自然的冷光，是人工LED灯的冷白光，从管道井前方的一个向下开口处透上来。

他爬向那个开口。

开口下方是一条走廊——不是地下室的结构，更像是医院在后来的改建中加建的一层空间。走廊两侧的墙面新刷了一层浅灰色的涂料，地面铺着工业用防静电地板——在第三地下区的任何地方都不会出现这种新材料，除非是有人不惜成本从上层区域运进来的。

白景行在这座废弃医院的地下建了一个数据中心。

林深从管道井口跳下来，落在了走廊的地面上。他的靴底接触防静电地板时发出了一声轻微的摩擦声响——脚步声在一秒钟内被走廊尽头的某样东西回应了：一盏感应灯亮了。

他沿着走廊向前走。两侧没有门——走廊是封闭的，唯一的光源是每隔几米感应亮起的顶灯。走廊的尽头是一扇厚重的钢制门——和废城铁拳兄弟会的工坊使用的安全门是同一型号，但门上没有安装电子锁，只有一个老式的机械转轮把手。

林深把手掌放在转轮上。金属触感冰冷，表面没有灰尘——被人定期擦拭。

他转动了转轮。

钢制门在打开时发出了一声低沉的金属摩擦声，门缝中的光线在这声摩擦中逐渐变宽——从一条线变成一掌宽，然后变成一扇门的完整轮廓。

门后是一个大约一百平方米的空间。

林深在最初的几秒里无法快速处理眼前的一切——不是因为场景复杂，是因为和他预期的落差太大。他看到的不像是太平间——天花板上吊着四排LED灯管，全部亮着。地面铺着同样的防静电地板。空间被划分成两个区域：外侧大约一半的面积摆着几排旧金属架，上面整整齐齐地码着一个个灰色密封箱——数据中心常用的硬盘冷存储箱。内侧是一个工作区——一张大尺寸金属桌，桌面上摊着几块拆开的电路板、三台不同型号的终端设备，还有一台体积不小的旧式投影仪。

一个男人坐在那张桌子的后面。

他看上去大概五十岁出头，但实际年龄可能比外表更大——地下区的生活条件会加速人的衰老。头发灰色偏多，剪得很短，不像是有意打理的，更像是用剪刀自己对着镜子剪的。穿着的是一件深蓝色的旧工作服——曾经的医用消毒服，褪色了，洗得很干净但布料在袖口和衣领处已经磨薄了。他的脸上有一道很清晰的疤痕，从左侧颧骨延伸到了左下颚——不像是战场伤，像是一次手术后留下的切口痕迹。

他的视线没有从林深身上移开过——当他听到门打开的声音时就抬起了头，然后就没有再低下头。他没有站起来，没有做任何防御性的动作。他就这样坐着，看着林深，眼神里没有恐惧——只有一种林深无法完全解读的东西，像是一个人等某个人已经等得太久，以至于当那个人真正出现时，他的第一反应不是惊讶，而是一声无声的、毫无动静的确认。

「你来了。」白景行说。

他的声音让林深感到意外——比他想象中要轻松，没有一个在地下住了几个月的人那种被环境压扁之后的干哑和疲惫。白景行的语气里带着一种奇怪的平稳，像是在和一个已经认识很久的人说话。

林深在门口站着，没有走进去。

「你认识我。」

「我没见过你——」白景行说，「但我认识你的脸。」

他停了一下。然后他说出了那句让林深后颈汗毛竖起来的句子——不是因为句子本身，而是因为他说这句话的语调平淡得像在描述今天的天气：

「你长得真像你爸。」

## 三

林深没有动。他站在门口，钢制门的重量压在他右肩上——他把它推开了一半，卡在那个位置没有完全打开。那句「你长得真像你爸」像一个在空气中悬停的指令，把所有动作都按下了暂停。

「你认识林国栋。」林深说。不是疑问句。

白景行把身体向后靠了靠，椅子发出一声轻微的金属吱响。他没有回避林深的目光，也没有用语言来填补沉默——只是同样安静地回看着他，像是对这场沉默感到某种程度的熟悉和舒适。

「国栋是我在泰坦研发中心的第一位搭档。」白景行说出这个信息的方式，像在读一条已经存储了很久、终于等到权限被解锁的备忘录，「我们从零开始搭建了泰坦的义体神经网络架构——后来你母亲加入，我们三个人从零开始建了另一个项目。」

「什么项目？」

白景行没有立刻回答。他看着林深，像在评估一个被隐藏了很久的问题应该被回答到哪种深度。

「你吃晚饭了吗？」白景行问。

这个问题来得太突然，让林深的大脑一时没有完成语义切换——他在三秒钟后才意识到白景行问的是一个生活问题，不是隐喻。

「——什么？」

「你走过来花了大概四十分钟。」白景行说，「从中转站北出口到这里的路线我知道有多长。你在路上没有停下来吃过东西，你的背包不在身上——你把它留在了路上某处。你进我门之前没有吞过任何东西，你的代谢声音在说话时有一点延迟——那表示你的血糖偏低。」

林深没有说话。不是因为被看穿了什么而感到不适——是因为这种观察的方式太像他自己。白景行在用他在新天城灰衣训练中学到的方式观察他——不，比灰衣训练更早，这是科学研究者在实验室里训练出来的观察方法：精确到不该被注意的细节，冷静到不像是一个普通人在做判断。

「我带了压缩饼干。」林深说。

「那不叫晚饭。」

白景行从工作台下面拿出一个旧式金属保温壶和一个干净的玻璃杯，放在桌面靠近林深一侧的位置。他给自己也倒了一杯——热水，有淡淡的茶味，但不是茶叶——是第三地下区常见的一种能泡出颜色的野草，味道苦涩但含一点微量营养素。

「坐下来。」白景行说，「我不会跑，你也不会抓我，我们不需要在门口站着互相试探。」

林深在门框边站了大约两秒。然后他松开了转动把手的手，让钢制门在自身重量下缓慢合拢，发出一声沉闷的碰锁声。他走到白景行的桌前，在对面的一把折叠椅上坐了下来。

他没有碰那杯热水。

「你从什么时候开始躲在这里的？」

「三个月前。」白景行把杯子捧在手里，没有喝——只是用手掌的温暖传递到杯壁上，「准确来说是九十一天。泰坦研发中心的第六安全规章是在员工知情后十二小时内执行保护性监视——我在触发那条规章之前走的。」

「什么规章？」

「你父亲死后第四年更新的一条安全条文：凡接触到泰坦核心项目完整数据链的员工，离职或主动解除劳动关系前需要进行四十八小时的过渡期安全审查——」白景行说到这里，嘴角出现了一丝极淡的、几乎没有弧度的变化，「但在执行层面上，这个审查的终点是总部的安全撤离中心——不是让你回家的。」

「所以你在被『审查』前跑了。」

白景行喝了一口热水，没有回答这句话。

林深在等待了片刻后，换了一个问题：「克莱恩和你联系过。」

白景行放下杯子的手在半空中停顿了大约零点三秒——极小的一下，但林深捕捉到了。

「你知道克莱恩？」

「我不只知道他。我刚才从末班车过来——他刚和我见过面。」

白景行的表情经历了一次极微妙的变化——不是意外，是重新调整对林深档位的一个瞬间。他的目光从林深的脸上移到林深夹克左侧略微鼓起的内袋位置，然后移回来。

「那你知道他快死了。」

「知道。」

「那你知不知道他为什么把泰坦研发中心搬到地下区？」

「因为他和钱爷做了交易。」林深说，「钱爷出钱，铁穹管安全，泰坦占七成。」

白景行沉默了很久，久到林深以为他不会回应了。但在那段沉默的末尾，白景行说了一句让林深没有预料到的话：

「那他告诉你交易里的第四项了吗？」

林深没有接话。

「我猜他没有。」白景行的声音里第一次出现了一种情绪——类似于遗憾，但比遗憾稍微锋利一点，「钱爷出钱，铁穹管安全，泰坦占七成——这些都是桌面上的。但桌面底下还有一项：实验室搬到地下区之后，第一批投入使用的实验样本——」他停了停，「——是林国栋和沈琳的备份。」

林深放在膝盖上的左手手指在同一瞬间全部收紧，又在同一瞬间控制住了自己放松下来。

「什么备份？」

「你父亲在泰坦总部地下18层——你母亲死前一年——藏了一个数据。」白景行的声音恢复了之前的平稳，但那种平稳中多了一层更紧密的质感，「不是研究数据，不是义体设计图——是你母亲的完整神经映射备份。包含她从出生到死亡前七天的全部记忆。」

林深没有动。

但他的大脑在那个瞬间只剩下一件事在回响——那趟开往记忆深处的、已经断裂了十年的列车，又重新出现在了铁轨上。

「你父亲把它藏在泰坦总部地下18层的离线备份服务器里。」白景行说，「他知道自己会死——他提前做好了准备。」

林深的声音在他说出下一句话时比他自己预期的要低，但很稳定：「我怎么证明你说的是真的？」

白景行没有用语言来回答他。他伸手从工作台侧面拿过一部平板终端，唤醒屏幕，输入了一串密码，然后把屏幕转向林深。

屏幕上是一张照片。

照片里是一面墙，墙面是未经装饰的灰色混凝土——不是办公区的装修风格，是泰坦总部建筑结构手册里的标准核心筒材料。墙面上用深色记号笔写着一行字。字迹有些歪斜，像是书写者在一种不舒适的身体姿态下完成的——但笔画的力度很深，每一划都嵌入了混凝土表面的气孔中：

「小深，妈在下面等你。——爸留」

林深看着那行字，很长时间没有动。

平板终端的屏幕自动熄灭在定时关闭的倒计时终点。

林深的视线仍然停留在那个位置——停留在屏幕熄灭前他看到的那行字的最后两笔笔画的记忆里。

白景行没有催促他。他安静地重新捧起那杯热水，在防静电地板反射出的冷光中等待着。

「你爸——」白景行在那段漫长的沉默接近末端的时候开口了，他的声音恢复了那种不带感情色调的科研语气，「他叫它「凤凰计划」。将人的意识完整上传到云端——但不是在死后才启动的。是在死亡到来的同时传输。」

「为什么叫凤凰？」

「因为凤凰要从灰烬里重生。」白景行说，「你妈是第一个实验体。你爸是第二个。」

林深的手指微微收紧。他感觉到从身体深处升起一种不属于恐惧、不属于愤怒、也不属于悲伤的东西——一种他无法命名的温度，在他的肋骨间缓慢扩散。

「备份现在在哪？」他问。

「在泰坦总部地下18层服务器的离线存储阵列里——但今天已经是它的转移程序启动后的第七天。」白景行说，「钱爷的人已经抵达了泰坦总部。他们正在把它拆出来，打包——运到地下区的新实验室。」

「所以我还有多久？」

「五天。」白景行说，「五天之内如果你拿不到那份备份——它就永久属于钱爷了。」

林深站起来的时候，膝盖碰到了折叠椅的金属腿，椅子在防静电地板上滑出了一小段距离——这是他从进入这个房间以来做出的第一个不精确的动作。

「你为什么要告诉我这些？」

白景行抬头看着他。在头顶LED灯管的冷白色光线下，他脸上的疤痕显得比刚才更深了一点——像一道刻在旧木头上的裂纹，从表面一直延伸到看不到的深处。

「因为我有件事一直在等一个合适的人来替我做。」白景行说，「我在等你长到足够大的那天——来听我讲完一个你父亲当年没有时间讲的故事。」
