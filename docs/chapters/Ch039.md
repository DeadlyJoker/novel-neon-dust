# 第三十九章：「地下的王国」

## 一

废城的早晨不是亮起来的，是响起来的。

先是铁锤砸钢板的咣当声——住在旧厂房一层的铁匠阿宽每天六点准时开工，他的炉子是用废弃磁轨的线圈改的，烧的是中枢区淘汰的旧义体零件，熔出来的合金能打菜刀也能打子弹。然后是塑料布帐篷里此起彼伏的咳嗽和孩子的哭声。接着是炖锅的咕嘟声——废城的公共厨房设在旧办公楼的一楼大厅，三口大铁锅从早煮到晚，里面永远有东西在沸腾。

林深是在这些声音里醒来的。他睡在医疗站角落的一张行军床上，盖着一条不知是谁放在他身上的毛毯——灰色，边角磨破了，但洗得很干净。左臂义体在休眠状态，液压管的冷却系统低鸣着，像一只趴在床边打呼噜的老猫。

他坐起来，看了一眼墙上的钟——上午九点。他睡了六个小时。这是过去七十二小时里他睡过最长的一觉。

老狗躺在他旁边的病床上。机械脸的损坏部分暂时用绷带包着，露出下面暗红色的生物组织。他的右眼睁着，正在看天花板上的裂缝。

「醒了？」林深说。

「醒了。」老狗的声音含混，「你那个屏蔽贴片也给我来一片，我这脸疼得想把脑子拆了。」

林深检查了老狗的颅内压力——正常。出血已经吸收，颞骨裂口愈合情况良好。他换了药，重新包了绷带，给老狗打了一针镇痛剂。

「苏焰呢。」

「在外面。」老狗用下巴指了指窗外，「帮你管你那摊子事。来了八个病人，都是废城的，一大早就排队。那个断腿的女的——你昨晚给她换义体关节那个——今天居然拄着拐来了，说要谢谢你。」

「谢什么。」

「谢你没收她的诊金。」

林深穿上外套，走到医疗站门口。门外确实排着队——不是正规的队，是一群废城居民散坐在走廊的破椅子上，有人在聊天，有人在打盹，有人在用废铁片磨指甲。看到林深出来，所有人同时抬起头。

「林医生！」

「林医生早。」

「林医生你吃了没？我带了面——方便面，中枢区的货，还没过期。」

一个老太太颤巍巍地从椅子上站起来，手里端着一个搪瓷碗。碗里是一团还在冒热气的面，上面搁了一个煎蛋——蛋的边缘煎得有点焦了，但蛋黄是完整的。

林深想起了三天前苏焰在他家厨房煎的那个蛋。

「不用——」

「拿着。」老太太把碗塞进他手里，力气大得不像是她这个年纪该有的，「废城的规矩：新来的头三天免费吃。不要钱。你在这里开了诊所，你就是咱们的人。」

林深看着那碗面。方便面。地下区的硬通货——一包方便面能换两次基础的义体润滑。蛋是新鲜的，蛋壳还在碗边上粘着，像是不小心掉进去的。

他端起碗，在走廊的台阶上坐下，开始吃面。

面泡得有点软了。蛋的盐少了。汤里有一股淡淡的铁锈味——废城的水是从旧管道里引的，过滤系统不完美。但这是他在这三年里吃过的——除小满煮的面之外——最好吃的东西。

苏焰从走廊那头走过来，手里拿着一沓手写的病历卡。她穿着废城居民给她的旧夹克——袖子太长，她卷到了手肘。她的头发扎成了马尾，发尾上沾着一小块银色的焊接碎屑。

「废城没有电子病历系统，」她说。「每个人都得手工记录。」

「你能弄一个。」

「能。但你得先给我搞一台能用的终端。」

林深喝完最后一口汤，把碗放在台阶上。「等下。」

他吃完面的这几分钟里，老太太已经走进了医疗站。她坐在老狗的病床边，从口袋里掏出一个小布袋，倒出几颗褪色的药丸。

「这是我老头子以前囤的止疼药，中枢区的，还没过期。」她把药丸放在老狗的床头，「吃吧，孩子。脸上的伤不能忍。」

老狗看了看那些药丸，又看了看老太太。

「大婶，你知道我是谁吗。」

「不管你是谁。」老太太站起来，把布袋塞回口袋，「这里是废城。在这儿，疼就得吃药。」

她走出医疗站的时候，在门口停了一下，看了林深一眼，笑了一下。皱纹挤在眼角，像是那些铁皮屋顶的裂缝里长出来的树根。

「林医生，你那个妹妹——醒了。」

## 二

小满坐在废城公共厨房的角落里，面前放着一碗炖菜。

炖菜的内容很难说清楚——大概是某种植物的根茎、几块不知道是什么动物的肉、一把粉丝、还有一团化开了的土豆泥。颜色是深棕色的，冒着热气，闻起来有八角和酱油的味道。这是废城的标准早餐——「乱炖」，旧城居民叫它「活下去」。

小满用筷子夹起一块肉，放在鼻子前面闻了闻。

「这是什么？」

「可能是老鼠。」阿三的女儿坐在小满对面——一个七八岁的女孩，头发剃得短短的，脸上全是灰。她没有穿鞋，脚底板的茧子比林深的手指还厚。「也可能是蛇。我爸说废城的肉不分种类，只要煮熟了都能吃。你吃不吃？不吃我帮你吃。」

小满把肉放进嘴里，嚼了嚼。

然后她的眼睛亮了。

「好吃。」她说。声音里带着一种很久没出现的、属于十四岁女孩的语气——不是敷衍，不是安慰，是真的觉得好吃。「比我哥煮的面好吃。」

厨房里做菜的大婶——一个胖乎乎的、围着三条围裙的女人——听到了这句话，笑得整个锅都在抖。

「好孩子！再来一碗！」

小满吃了两碗。

吃完之后她主动把碗拿到水池边洗了。废城的水池是用旧水槽改的，水龙头拧开之后要先等十秒——等锈水流完了才是清水。小满等的时候把碗举到灯下，看水槽边上贴着的旧瓷砖，瓷砖上画着小小的花——是幼儿园小孩的水彩画，颜色已经褪得差不多了。

「谁画的？」她问。

「我。」阿三的女儿从她背后探出头来，「去年画的。好看吗？」

小满看了很久。然后她从口袋里摸出铅笔，在那朵花旁边画了一朵新的——不是天空，不是电路图，不是任何她在梦里看到的东西。

是一朵向日葵。花瓣歪歪扭扭的，花心涂成了金黄色。

「好看。」阿三的女儿说，「这是什么花？」

「向日葵。地面的花。会跟着太阳转。」

「你见过太阳吗？」

小满想了想。「在梦里见过。」

她把铅笔放回口袋，把碗放在架子上。向日葵在旧瓷砖上安静地开着，花瓣上沾了一滴从水槽龙头里滴下来的水珠，在废城暗红色的天光下，亮得像一颗刚从地底挖出来的种子。

林深在门口看着这一幕。

他没有走进去。他就站在门口，把这一刻的画面存进脑子里——小满蹲在废城厨房的旧水槽边，给一个从没见过的陌生小孩画一朵花。她的手指还握着铅笔，但这一次，她画的不是信号，不是图案，不是那些她不应该看到的东西。

她画的是一朵真正的花。

老狗不知什么时候拄着拐走到了他身后。

「你妹妹——」老狗的声音还是含混的，但比刚才清楚了一点，「看起来好多了。」

「屏蔽贴片起作用了。」林深说，「暂时。」

「多久。」

「二十天。最多。」

老狗沉默了一会儿。他的机械脸虽然碎了，但那只好眼里有一种林深很熟悉的东西——是信息贩子在汇总情报时的专注。

「二十天够干什么。」

「够给泰坦找点麻烦。」

林深转身走向医疗站。走廊里排队等诊的废城居民自动给他让开一条路，不是怕他——是尊重。在这里，一个不收钱还肯救命的医生比十个帮会的保护承诺更值钱。

## 三

林深在废城的第二天做了十一台手术。

不是义体改造。是基础医疗——脓肿切开、骨折固定、感染清理。废城的居民常年缺医少药，很多人的伤是从一年前就开始的，拖到化脓、拖到坏死、拖到快没命了才来找他。他用自己随身带的基础器械，加上废城居民捐的东西——一把生锈的止血钳、半卷过期的缝合线、一台只有半速运转的消毒柜——把每一个能救的人救回来了。

第十一个手术做完的时候，已经是凌晨一点。他的手指在连续工作了十六个小时后开始发抖——右手先抖，然后是左手义体的伺服电机开始变得不那么精准。他把手术刀放下，在洗手池前站了三分钟，让凉水冲着手指。

苏焰走进来。她手里端着两杯茶——废城的茶，用旧茶叶泡的，颜色深得像墨水。

「你该休息了。」

「还有三个。」

「明天。」

林深接过茶喝了一口。苦得差点咳出来。苏焰看着他被呛到的表情，嘴角动了一下——不是笑，是那种保持了很多年的表情面具下漏出来的一点裂缝。

「废城的信息网络今天恢复了。老狗修好的。」她说，「我在网上查了一件事——关于你的左臂。」

林深放下杯子。

「查到了什么。」

「你的左臂型号在任何正规渠道都不存在。灰衣的数据库、泰坦的产品目录、甚至铁穹军工的销售记录——这条手臂的型号在所有系统里都被抹掉了。唯一的一条记录——」她把数据板放在洗手台上，翻到最后一页，「在三年前泰坦生物的一份保密招标文件里。项目代号——PX-0714。」

林深看着那个代号。

PX-0714。三年前。他二十一岁。在地下区最穷的时候，连诊所都没有，每天靠在垃圾站回收废弃义体零件卖给黑市维生。有一天，黑市上来了个中间人——不透露姓名，不透露背后的金主，只说有一批「特殊项目」需要志愿者。条件是切除左臂，植入一套试验型的军用级义体。报酬是手术费全免，外加十万信用点。

他签了。

那时候他妹妹刚被诊断出来，三百万的手术费像一个永远不可能到岸的海。十万信用点只是零头，但至少能续三个月的命。

「你参加过他们的试验。」苏焰说。

「自愿的。」

「知不知道那个试验项目是什么级别？」

林深没有回答。

苏焰把数据板推到更近一点。

「PX 是泰坦最高密级项目的代号前缀。只有永生者议会的核心成员发起的项目才能用。PX-0714 的项目负责人——」她翻到下一页，「是王景明。」

林深低头看着终端上那张照片。一个老人——头发全白了，眼睛很亮，嘴角有一道细小的手术疤痕。照片下面的简历栏里写着：「王景明，泰坦生物联合创始人，永生者议会议长，神经工程学首席科学家。2120年3月去世。」

三年前。他去世的那一年。他签下志愿书的那一年。

「这个项目的具体内容——你有吗。」林深问。

「被封存了。我的权限打不开。但老狗从废城的一个老技术员那儿拿到了一份残本——泰坦研究院三年前被销毁的档案库里泄出来的碎片。里面有几行字。」

苏焰把那几行字调出来。

「PX-0714：意识数字化协议实验。项目目标——将人类完整意识从生物载体迁移至义体系统。」

林深读了三遍。文字很冷，像是从某本被烧掉半边的实验手册上撕下来的。

意识数字化。把人的意识放进机器里。不是上传记忆，不是复制人格——是迁移。是让一个活着的人不再需要肉体，只靠义体系统和数据网络维持存在。而项目的第一个成功实验体——如果文件是真的——被植入了一套代号为「普罗米修斯」的军用级义体。

他低头看了看自己的左手。

液压管道还在轻微震动，外装甲上还粘着昨天手术时留下的血迹。他的左手救过几百条命。他的左手在铁轨枕木下推开过一条三米长的裂缝。他的左手在过去的三年里是他最可靠的武器和最沉默的伙伴。

「三年前签那个合同的时候，」林深的声音很轻，「中间人说这套义体是泰坦淘汰的项目样机——性能过剩，但成本太高，不适合量产。所以给我用，算废物利用。」

「他骗了你。」

「他没有。」林深把左手翻过来，看着手背上的装甲面板。面板的边缘有一行微小的序列号——他看了三年，从来没想到过去查。

PA-001。

「他没有骗我——是因为他自己也不知道。」林深站起来，走到窗户边。窗外是废城的夜晚——塑料布帐篷里透出来的暖黄色灯光，旧水塔顶上的信号灯一闪一闪，远处中枢区的人造天光像一层发光的纱布盖在废墟上。

「他知道的是——这套义体是泰坦淘汰的。」

「他不知道的是——它是泰坦藏起来的。」

苏焰走到他旁边。她看着他的侧脸——霓虹灯的光从窗户里漏进来，在他颧骨下面画出一道深色的阴影。

「所以你参加的那个试验——」

「不是试验。是藏匿。」林深把左臂慢慢握紧，液压管发出低沉的声音，「王景明在去世之前把他的项目核心——那套意识迁移协议——藏在了我这套义体的底层系统里。他用我当保险箱。」

「为什么不直接销毁？」

「因为他不信任泰坦。」

苏焰没有说话。她的灰衣训练让她对泰坦的内部斗争知道得比谁都多——永生者议会不是铁板一块。创始人之间的分歧从建城之初就存在，王景明是其中唯一的理想主义者。他不相信公司，不相信制度，不相信把意识数字化之后的人类还能被称为人类。

所以他把自己的最大成果藏在一个欠了十万信用点的地下医生的左臂里，希望有人能替他让这个秘密活下去。

「那他现在在哪。」苏焰问。

「死了。」林深说。「2120年3月。」

「但你说——」

「我说他的项目核心在我的这里。」林深把左手按在自己胸口——在义体和血肉交界的地方。「意识迁移协议。」

他停了很久。

「如果这个协议是完整的——如果有人把他的意识迁移到了这套义体里——那他可能还在这里。在代码的某一段。在数据的某个地址。在我每次打开义体底层系统的时候——在我看不到的角落。」

窗外，废城的灯光一盏一盏熄灭。阿三的女儿在帐篷里抱着向日葵的画睡着了。老狗在医疗站的床上开始打鼾。小满在最好的那间房里翻了个身，铅笔从手指间滑落，滚到了枕头底下。

苏焰伸出手，放在林深的左手腕上。

她的手指温热的——不是义体，是真正的人类体温。她的触感穿过他的义体装甲，穿过液压管和伺服电机，落在里面那层最薄的感知膜上，在那里变成一串很轻的、几乎注意不到的触觉信号。

「如果你想知道他在不在——」她说，「打开看看。」

林深低头看着自己的左手。那套义体他用了三年，修了无数次，改了无数次，熟到闭着眼睛都能拆装每一个零件。但他从没看过它的底层代码不是他自己的写的那些。

他怕看到的不是代码。

他怕看到的是一个人。

站在废城的夜色里，站在苏焰的手还放在他左手上的温度里，站在妹妹终于安稳睡着了的安静里——

他把左臂的控制面板打开了。
