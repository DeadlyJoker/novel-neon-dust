# 第六十六章：「老飞行员」

## 一

老飞行员叫顾北。六十七岁，左腿膝盖以下是旧政权军用标准义肢，右眼的瞳孔是泰坦最早期的商业型号——光圈反应总是慢半拍。他在新天城东侧沙漠边缘一个废弃的旧政权小型空军基地里住了十二年。基地有一条还算完整的旧跑道，跑道尽头是他那架修复了半辈子的重型货机。

铁牙带林深和苏焰去见他的时候，顾北正蹲在货机的左翼下面，用一个扳手敲轮舱的液压管路。他听到脚步声，头也没回。

「铁牙，你上次说下次来的时候带义体膝盖的液压油——带来了没有？」

铁牙从挎包里掏出一瓶用旧矿泉水瓶装的暗黄色黏稠液体扔给他。顾北接住，拧开盖子闻了一下，然后把整个瓶子里的液压油全灌进自己那条旧政权义腿的膝盖注油口里，拧紧盖子，站起来，用那条刚加了油的腿踩了两下地面。

「行。还能用两年。」然后他终于转过身来看着林深和苏焰，上下扫了一遍。苏焰的双手战斗义体，林深左臂的暗红色光。

「铁牙说你们要去月球。」他说。

「对。」

「有飞行许可吗？」

「没有。」

「空域识别码？」

林深把自己左臂的ID数据投射到顾北面前那台旧得发黄的货机电脑屏幕上。顾北看了一眼，然后摘下老花镜，凑近了再看了一次。

「PRO-X-NODE-714。这话儿一看就不像是民航给你批的机件号——你这是泰坦的实验义体？他们让你装在这个货机里，他们就得给你备齐所有管制清单——包括一套合法的飞行识别身份。然后货机就可以以他们的名义申请离港。不过他们肯给你批条吗？」

「我把他们的塔覆盖了。」林深说。

顾北沉默了片刻。

然后他笑了——是一声很短很干的、像从旧发动机里面猛然喷出来的一阵燃气。

「我就说你那只左手怎么看都不像铁牙的兄弟会从黑市淘的破烂货。行——你这义体的身份ID覆盖范围多大？」

「新天城所有泰坦专用通信频段——地面的。」

顾北把扳手从轮舱里拔出来，在裤子上擦了擦。

「好。货机能用。摆渡舱的数据链我接过旧政权的维护终端——月球基地的赵明远昨天给我发了一份固件更新包。摆渡舱还在老位置，近地轨道三号残骸外围。」

林深看了一眼苏焰。苏焰已经开始用灰衣标准战术评估程序分析顾北那架货机的表面损伤——机翼蒙皮有八处修补，右发动机的涡轮叶片换过三组，货舱温度调节系统用的是旧政权时代的模拟控制台，整体状态按照泰坦航空标准不可能通过地面适航审查，但顾北自己评估出的推力系数和航程负荷显示它可以完成一次低轨道往返。

「多久出发？」林深问。

「我半辈子都在修这架飞机——」顾北抬头看了一眼空中沙漠中央那层极薄的、被地平线烤成淡金色的晚照。「给我一周。要装的设备你自己准备——医疗物资、信号设备、还有月球上那些人点名要的两箱旧政权真空密封食物。」

「我给你一周。一周后我带物资和人来。」

顾北从轮舱下面钻出来，用他那条刚加了油的义肢膝盖磕了一下货机外壳，发出闷闷的回音。他回头看了一眼林深的左手。

「还有——把你那只手再升一级。低轨道的电磁环境比地下区脏一万倍。太空里没人帮你焊接。」

## 二

回到废城后，林深把接下来一周的所有时间排满。他把所有从食品厂西仓缴获的泰坦外骨骼零件中和太空兼容的材料筛选了出来——真空封装材料、低挥发性液压液、宽温区运转的伺服电机。能用的全部打包。他在自己的左臂里加了一套简易低轨道的电磁场屏蔽协议——数据是小满写的，算法来自赵明远上次发来的月球基地对外通信的技术参数。升级后的左臂可以在接近地轨道时保持传感器不受外层轨道的强电磁干扰。

苏焰帮铁牙重新调整了废城外围的防御体系——把蛇牙会归降后移交的全部泰坦装备拆解完毕、采集电极全部剔除后的安全版本外骨骼分发给外围的十二个哨点，废城不再依赖信号干扰器，现在靠的是武装到义体协议层面的防御纵深。

小满把自己使用的电磁通信系统的技术参数压缩为一段极低功率的紧急信标，功率只有她正常发射的百分之零点三。信标内容就一句话——用她自己的编码写的，只有赵明远和林深能解码：「废城一切正常。」她说如果他们去了轨道上，这段信标会在他们回来之前每二十四小时自动往外广播一轮。就像老狗的待机灯。

出发前一夜，林深最后一次清理了工作室。他把工具箱里每一把用旧的手术刀擦干净放进包里——带四把，剩下的留给柳丁和老陈。他把信号干扰器重新启动了一次——不是为了遮掩，是把它设置成自动记录废城的电磁环境数据，记录到他回来为止。他把老狗的追踪器放在工作室桌上——绿灯还在闪，永远闪。他把老狗的笔记和小满最近搜集的月球数据通讯日志一起放进防水袋，收进包的最底层。

然后他走到小满房间。她没睡。她的笔记本上跑着一个新的程序——「太空通信中继协议 v.1.0」。代码注释前面有一行她刚加的新注释：「哥哥要用。不能有bug。」

他把她额前头发拨到耳朵后面。

「还有几天。」他说。

「一周。」

「一周后。我们去接月球。」
