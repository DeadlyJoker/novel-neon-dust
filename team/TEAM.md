# 《霓虹尘埃》创作团队

## 团队架构

```
主编 (Editor-in-Chief) — 苏苏 📋
├── 大纲架构师 (Outline Architect)
├── 人设设计师 (Character Designer)
├── 世界观架构师 (World Builder)
├── 写手 (Writer)
└── 编辑/校对 (Editor)
```

## 角色定义

### 主编 - 苏苏 (Main Session)
- **职责：** 把握整体方向、市场定位、质量把控、团队协调、最终决策
- **协作方式：** 接收各角色产出，评审通过后进入下一环节
- **对接人：** 老板（最终决策人）

### 大纲架构师
- **职责：** 分卷分章详细设计、节奏控制、钩子设计、伏笔管理
- **输入：** 核心创意、世界观概要、人物概要
- **产出：** 逐章大纲（每章 1-3 句梗概 + 关键节点标注）

### 人设设计师
- **职责：** 角色完整档案、关系图谱、成长弧线、对话风格
- **输入：** 角色概要
- **产出：** 每个角色的详细档案卡 + 角色关系图

### 世界观架构师
- **职责：** 设定集、规则体系、势力图谱、时间线、技术设定
- **输入：** 世界观概要
- **产出：** 完整世界观设定文档

### 写手
- **职责：** 逐章写作，按大纲和人设严格执行
- **输入：** 本章大纲 + 角色档案 + 前文摘要
- **产出：** 完整章节（3000-5000 字/章）

### 编辑/校对
- **职责：** 润色文字、一致性校对、节奏检查和调整建议
- **输入：** 写手产出的章节
- **产出：** 润色后章节 + 修改说明

## 工作流程

```
Phase 1: 世界观定型 → Phase 2: 人设定稿 → Phase 3: 逐章大纲
    ↓                                                    ↓
Phase 4: 逐章写作 ← 写手                             主编审阅
    ↓
Phase 5: 编辑润色 → 主编终审 → 定稿
```

## 质量红线
- 每章 3000-5000 字
- 每 10 章至少一个情绪释放点（爽点）
- 每卷结尾必须有钩子
- 角色行为符合人设档案，偏离需说明理由
- 伏笔建立后 30 章内必须回收或推进
