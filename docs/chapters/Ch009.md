# 第九章：条件

## 一

铁拳兄弟会的总部不在某栋楼里——在楼下面。

林深跟着引路的人走过七号街区的尽头，拐进一条不起眼的货运通道。通道尽头是一扇钢制卷帘门，没有把手，没有门铃，只有侧墙上嵌着一个巴掌大的金属面板。引路人把手掌按上去，面板亮起一道红光，扫描了三秒，发出短促的蜂鸣。

卷帘门缓缓升起。门后的空气涌出来——热、干、带着机油和铁锈的气味。

总部是一个废弃的地下停车场改造的。层高四米，面积大得像一个足球场。水泥立柱上绕着霓虹灯管——铁拳标志性的暗红色——把整个空间笼罩在一种暧昧的光晕里。

远处有人在做力量训练，液压管嘶嘶作响；有人在焊东西，电弧光在红雾中一闪一闪。这座地下城有自己的心脏和呼吸。

引路人把林深带到停车场深处的一个隔间。不是办公室，更像一个指挥岗——防弹玻璃围成三面，里面摆着一张铁桌、两把折叠椅、一面挂满地图的墙。

桌上摊着一张手写的名单。林深扫了一眼，看到了几个熟悉的地名和数字——货运站、回收线、每周的流水。

铁牙就坐在其中一把折叠椅上。他没穿风衣，只穿一件灰色工字背心，两条全是钢铁的手臂裸露在外，在暗红灯光下泛着哑光。机械右手的关节处，那个标志性的金属牙套格外扎眼。他的光头反着光，头顶那道贯穿前后的旧疤像一条干涸的河床。

「坐。」他没有站起来，用下巴指了指对面的椅子。

林深坐下。

两个人中间隔着一张铁桌、一个烟灰缸、一瓶没开封的廉价白酒。

沉默持续了大约五秒。

铁牙拿起酒瓶，用牙咬开瓶盖——不是用那条机械右手，是用真牙。「嘎嘣」一声，金属瓶盖被咬成一个变形的圆片，落在桌上。

他给自己倒了一杯，推到林深面前。

「喝不喝？」

林深看着那杯浑浊的液体：「喝了再谈？」

「喝不喝不影响谈的结果。」铁牙给自己也倒了一杯，「但喝了是兄弟，不喝是买卖。」

林深拿起杯子，一口干了。辛辣的液体顺着喉咙烧下去，胃里腾起一团火。他放下杯子，没有皱眉。

铁牙看着他，笑了一声。不是嘲讽，是一种意料之中的满意——像赌骰子前就看到了点数。

「第4章的时候你拒绝了我。」铁牙说，「二十万，坐在你那张塑料椅子上，我亲自去的。记得么？」

「记得。」

「那天你说了很多理由。」铁牙把手臂搁在桌上，「我记得最清楚的一句是——『你的二十万没能解决我的问题，它只会让我的问题翻倍。』」

林深没有说话。

「所以你现在来，说明你的问题变了。」铁牙的手指轻轻叩着桌面，「要么是新的问题比旧的问题更大，大到让你觉得翻倍也能接受。要么是——你发现不翻倍的话，你会死。」

林深把那张皱巴巴的诊断报告从口袋里抽出来，推过桌面。

铁牙接过来，低头看。他的阅读速度很快——几秒从第一页翻到最后一页。然后他把报告放在桌上，手指压在「三百万」那行字上，沉默了片刻。

「你妹妹。」

「嗯。」

「多长时间？」

「三个月。」

铁牙把报告折好，推回林深面前。他没有说节哀，没有说难搞，没有说任何一句废话。他只是看着林深，眼底有一层很薄的光——不是同情，是一种「我知道这个数字意味着什么」的眼神。

「林深，你知道为什么我上次亲自去？」铁牙靠回椅背，「不是因为我闲。是因为我打听到了。七号街区的林医生为了妹妹什么都敢做。我当时想——这样的人，要么用得着，要么养不起。如果哪天他主动来找我了，那说明他已经没有别的路可以走了。」

「我就是这样的人。」铁牙继续说，「成也好，败也好，做事之前先把人的底算一遍。你站在我的位置你也得这么做。」

林深的目光从铁牙脸上移开，落在桌上那瓶白酒的标签上。标签已经磨损得看不清字了，只剩下一个模糊的商标轮廓，像被时间泡烂的决定。

「我要三十万。」林深说。

「预付？」

「预付。剩下的分期从我报酬里扣。」

铁牙没有马上回答。他拿起自己的杯子喝了一口，酒液在他嘴里含了两秒才咽下去。

「三十万不是小数目。」

「你上次带了二十万现金到我诊所。」

「那是买你。现在是买你妹妹的命。」铁牙放下杯子，「不一样。前者是投资，后者是人情。生意人最怕的就是人情买卖。」

林深的手指在桌沿上停了一下：「那你想要什么？」

「我要你签合同。」

铁牙拉开铁桌右手边的抽屉，从里面取出一份文件。A4纸，五六页，封面印着「铁拳兄弟会·技术顾问服务协议」，字体是粗体的，排版很正规——正规得不像一个帮会起草的东西。

他把合同放在桌上，没有推过去，像一片还没有被踩过的地雷区。

「一份正式的合同。每个月固定报酬二十万，做兄弟会的专属义体医生。急诊加班另算。报销器械耗材，上不封顶。」铁牙的每一条都说得清清楚楚，「三十万预付，剩下的手术费从你未来的报酬里分期扣——扣完为止。」

「期限？」

「合同签三年。」

林深没有伸手去拿合同。他看着封面上的那些字，嘴角动了一下。不是笑，是某根神经牵动的抽搐。

三年的合同。二十二岁签，二十五岁解约。最好的三年在地下四米深的停车场里，给一个帮会的战斗员换胳膊换腿、拆信用锁、缝战斗伤口。

「如果我三个月内凑够剩下的钱呢？」

「合同依然有效。」铁牙说，「三年就是三年。你签的是专属协议——这三年里你不能接铁拳以外的任何手术。泰坦的诊金、别的帮会的活、急诊站的机位——统统不能碰。」

林深沉默。

「但你妹妹不会死。」铁牙补了一句，「我给了你时间。」

这个词从铁牙嘴里说出来的时候，林深感觉到某种沉重的东西缓缓落地了。时间——程远征说三个月，铁牙说有三年。虽然三年里有两年零九个月是还给铁牙的债，但小满的那三个月是铁牙垫的。

「你等我来。」林深说。不是疑问句。

铁牙没有否认：「我给你留了三个月的窗口。超过了，我也没办法。地下区没有哪家医院能给私人垫三百万。」

林深看着铁牙的眼睛。那里面有计算——精明的、老辣的、属于一个在地下区爬了半辈子的帮会首领的计算。但计算下面还有一层更厚的东西。不是善意，更像一种选择——铁牙选择了他。

「我能看看合同吗？」

「看多少遍都行。但要签，只签一份。」

林深拿起合同，从第一页翻到最后一页。条款写得干净利落——没有藏着掖着的陷阱，没有拐弯抹角的附加条件。简单得不像帮会的合同。

但他翻到第四页的时候停下了。

第四页有一个加粗的条款：「乙方（林深）在执行甲方指派任务期间发生的一切法律后果由甲方承担。」

法律后果。

林深的视线在这四个字上停了两秒。

铁牙察觉到了：「那是保护你的。你在铁拳的诊所里做手术，合法不合法，我说了算。」

「在法律上——」

「法律在地下区是个摆设。」铁牙打断他，「但你做得多了，难免有人拿它当棍子打你。这个条款的意思是：有人要查你，先过我铁牙这一关。」

林深没有再问。他把合同翻完，放回桌上。

「笔。」

铁牙从口袋里掏出一支签字笔——黑色的，笔帽上夹着一个磨损的金属夹。他把笔放在合同上，和林深的距离只有一只手臂。

林深拿起笔。

笔尖悬在签名栏上方，停了大概三秒钟。

那三秒里他想了很多事。想小满趴在磁共振检查床上的背影，想老狗蹲在巷子口喝酒的样子，想那台永远修不好的路灯，想三年合同里的每一个字。铁牙那张挂满地图的墙上，他看到了铁拳控制区的版图——三条货运通道、四家地下拳场、一条废品回收线。他的诊所不在上面。

但三年后，他会在这张地图上留下自己的印记。

笔尖落了下去。

「林深」两个字，一笔一划，写得比平时用力。纸上留下微微凹陷的笔痕，在背面能摸到字的轮廓。

铁牙拿回合同，确认签名，然后把合同锁回抽屉里。他没有立刻站起来。

「三十万明天中午到账。你写个账号给我就行。」

林深点点头。

「还有一件事。」铁牙站起来，走到墙上的地图前，「蛇牙会最近疯了。上周突了我们在北区的一个仓库，废了三个兄弟。两个断了腿，一个内脏破裂——现在还躺在我的医务室里。」

林深坐着，等着。

「医务室的医生姓秦，退休下来的军医，手艺一般。他处理不了那个人的伤。」

铁牙转过身来。暗红色的霓虹灯光打在他半边脸上，让他的五官看起来有深有浅，像一张刻在硬币上的头像。

「林医生，今晚有个活儿。」

他的声音沉下去，像铁块沉入水里。

「兄弟会的人去接他了，半个小时到。那是个重伤员——我不知道你能不能救活，但你必须救。」

那个「必须」两个字被他说得很用力。不是威胁——是铁牙自己的压力通过这两个字漏了出来。

林深站起来：「人在哪儿？」

「在运回来的路上。」铁牙看了一眼墙上的钟，「你的诊所设备不够，在总部的医务室里做。」

「叫秦医生准备好麻醉和基本器械。我带自己的手术刀。」

铁牙看着林深——这个二十二岁、刚签了一份三年卖身契的年轻人，此刻脸上没有恐惧，没有犹豫，只有一种在做决定之前就已经知道答案的平静。

「好。」

林深转身走出隔间。身后传来铁牙的声音：

「林深——」

他停下，没有回头。

「今天你签了这个名字。」铁牙说，「从今晚开始，你的手术刀就不只是你一个人的了。」

林深在暗红色的灯光里站了一秒，然后继续往前走。

地下停车场的空气又热又闷，混着机油和电焊的气味。他的脚步声在水泥地上响起，一步一步，节奏很稳，像一个已看清所有后果的人。

头上那盏霓虹灯管闪了两下，像一个正在眨眼的东西，在地下四米深的地方看着这个刚签了契的年轻人走进夜色——不对，走进地底。

铁牙站在隔间里，透过防弹玻璃看着林深的背影走远。他的机械右手慢慢地握紧又松开，握紧又松开，指节的金属牙套发出细碎的摩擦声。

他拿起桌上林深用过的酒杯，倒满，自己喝了一口。然后拿起合同，从第一页到第六页重新看了一遍。

最后他翻到第四页，目光落在「法律后果」那行字上。

不是保护林深的。他是在保护自己。

铁拳兄弟会签一个地下区最好的义体医生——这不是为了给手下治病的。蛇牙会的刀越来越快，泰坦生物的影子越伸越长。铁拳需要一个能焊住一切的人——焊住伤口，焊住漏洞，焊住兄弟会裂开的缝隙。

而林深的出现，给了他一张牌。

一张连他自己都还没想好怎么打的牌。

铁牙把合同收好，关灯，走出去。停车场另一头传来悬浮引擎的轰鸣声——运送重伤员的车到了。

他加快脚步。

今晚这个手术不只是对林深的考验。它会是铁拳兄弟会面子里子的一根定海针——如果林深能救活这个人，铁拳的人就会真正接受他。

但如果救不活呢？

铁牙的脚步慢了一拍，然后继续往前走。

他没有时间想这个问题了。
