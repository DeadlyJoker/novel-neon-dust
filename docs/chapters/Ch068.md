# 第六十八章：「月球」

## 一

摆渡舱在月球基地的旧政权着陆平台上降下来的时候，激起了一圈沉积了几十年的灰色月尘。月尘在低重力下缓缓升起来，像一层被吹反了方向的老水泥灰。基地的密封舱门早就开了——赵明远和他的二十几个同事列队站在着陆平台旁边的旧通道口。林深不认识其中的任何一个人，但又觉得他们每一张脸都在哪见过——在地下区的福利院，在老孟的诊所，在废城的每晚火堆边。底层的脸都有同样的质感。

赵明远比林深想象的老——头发白了一半，手上有冻疮和化学烧伤的旧疤。他的左腿义肢很老旧——大概是七年前的旧政权型号，液压管外包着好几圈透明胶带。他伸出手，林深握住了。不是公司之间的握手，是成年人——一个以被从所有官方记录里抹去自己姓名为代价换来这二十八条命的人，和一个用一只被公司当成数据采集节点的左手把自己妹妹的病治好了以后来到月球的人之间的握手。

赵明远带他们参观了基地。地方不大——旧政权时代一个半废弃的科研前哨站，由休息舱、实验室、水回收区和一个小型的室内作物培植架组成。培植架上的番茄个头很小，但赵明远说这是他们在月球上吃到的最好的东西。林深注意到了角落里堆着的旧设备里有一个眼熟的标签——泰坦生物，普罗米修斯项目外配实验设备清单。赵明远证实了这批设备的存在——它是王景明在世时、在被克莱恩篡改项目方向数年前，签发给月球基地小批量物资中的最后一批。王景明一直没有公开承认这份配送——但它救了月球上至少四个受伤的技术员。

那个叫阿正的年轻人坐在休息舱一角，在剥一根旧电线的橡胶绝缘层。他的左臂义体已经拆掉了——只剩齐肩的旧接口残端。他看到林深的时候抬起那只健康完好的右手向他挥了一下。

「你也是左臂。」他说。

「你也是。」林深说。

「我的坏了。没有备用处理器。赵老师说——你的左手能给我看看吗？」

林深在他旁边坐下。他把左手伸出来放在膝盖上，阿正看了很久——用的不是义眼，是这三年待在月球基地上每天除了种番茄就是研究电磁场的那颗人的大脑。然后他说了一句让林深心脏停跳了半秒的话。

「你左手里有一段不是你的代码——是一个女人写的。很老——大概在你出厂之前就被放进去了。」

林深把左手翻过来。他让阿正指给他看。阿正用旧电线的铜芯在舱壁上画了一个简单的框图——他没法精确解码数据层，但他能看到那段代码的存在方式是"在适配体与胚胎基因组之间建立非对称加密信道"。那是沈琳和小满那次单向对谈——从写在备注层里的备忘录、埋在最底层的数据保护壳中的那一行加密序列——直到刚才，在王景明设计的模块架构这一端被阿正一眼认出来。

「你妈妈是工程师？」阿正说。

林深把左手收回来。他知道沈琳之所以把这段代码藏在义体里最深的那层——是因为从备好到交给他的那天，她不在了。但代码预留的指令解码方式她在备注里写得很清楚。她直到不在的那一天都还在发信号。

他把左手从舱壁上放下来。

「是最好的那种。」他说。

## 二

赵明远说卫星网络从三年前旧政权最后一批微星燃料耗尽之后就全断了，他和几个技术员自己搭了一套短波通信系统，功率只够收发新天城到月球的信号。最近一次尝试往更远的轨道发信号是在林深的左手在三号塔里第一次主动回传信号后不久——赵明远说他的发射终端上收到的不是什么复杂的协议包。而是一段极其简单低频信号，频率刚好是：4.2千兆赫减半。2.1千兆赫。他做了一辈子的神经伦理研究，认识这个信号——那是人体基底节的正常α节律减半编码后的电磁对外共振。

「不是塔上发的。是一个人。那个频率跟你妹妹做完塔覆盖后的新频率完全匹配——你用自己的方式，从地下往太空发了人生第一次活体信号。那时候我决定不走了。」

林深没有回话。他看着窗外——不是地下区排气管裂隙里渗进来的那一条灰白，是陆舱窗外没有空气和大气的、完整到已经有些虚拟的月球表面。他把自己义肢里的振动传感器调到最低，听不到排气管里头的风啸声。只听到极轻微的内部冷却液循环，和隔壁房间里苏焰正在检查的一批旧的维生模块运转数据流。

然后小满从门边探头进来，手里拿着一颗番茄。她脸上全是番茄汁——不是偷吃，是陪赵明远的技术员做培植架PH值检测的时候，摘的第一个熟果没拿稳直接糊在自己脸上。苏焰在后面跟着进来，手里拿着一条湿毛巾，脸上是所有战斗义体全部解锁之前人类难得看到的一种表情——一个红发女战神在帮一个满脸番茄的小姑娘擦脸，还擦歪了。

苏焰用的还是左手。
